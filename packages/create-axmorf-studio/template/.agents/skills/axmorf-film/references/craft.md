# 画面手艺

先读 [导演手册](direction.md)。本页只补世界、构图和美术；节奏、混音、storyboard 与审片统一按手册。

## 一个世界，镜头跟着因果走

先想观众要记住的一句话，再把上一动作的结果变成下一动作的原因：证据抵达 → 旧判断碎裂 → 碎片重组为新判断。
多个句子可以共用一个世界；不要把一句旁白等同于一张新页面。章内靠主体变化、取景和平移推进，章节之间才转场。
配方只负责动作曲线，不能替代世界设计；从 [配方目录](recipes.md) 选技法，不原样粘贴构图。

### 划分章节与镜头路径

效果从内容语义决定。`AxiomMorph` 可用于短文字对照、重组或拆解；没有影片必须使用它，也不必解释未用原因。
在 `storyboard.md` 写出语义事件、句子 id 或经确认的关键词绝对帧、入场/落定/阅读帧。

- **按因果阶段划章**：问题、证据、机制、结论，而不是按句子或固定秒数。一个章节通常覆盖多句旁白；
  `FilmSceneTrack` 的 `chapter` 写阶段 id，同章场景不写 `enter`，默认连续硬接，视觉连续性由你保证。
- **每章定义世界**：主体住在哪里，证据从哪里来，哪些物件共享空间，前景遮挡什么、字幕留在哪里。
  有过程就搭比屏幕大的世界，标出世界坐标；没有空间关系就不为了“有镜头”胡乱漂移。
- **镜头跟随可见因果**：全景交代关系 → 跟随证据移动 → 特写作用机制 → 拉远看结果。写出起止帧、中心和尺度，
  每章至少有一次平移、跟拍或换位；阅读时镜头克制，关键文字稳定。先写进 `storyboard.md`，再动代码。
- **从实测时间反推动作**：句子 id、开始/结束帧来自 `film:voice`；预备、变化、到达、停稳来自配方 resolver。
  语义决定内容出现的句子范围；语义事件用精确 hit 与画面对齐，规律网格维持底层节奏，L3 重音误差 0 帧，不能挪旁白或字幕来踩拍。

### 跨章节才选转场

1. **优先覆盖式**：`mask-wipe` 对应证据或前景横过画面，`whip-blur` 对应快速跟随换空间，`light-leak` 对应光照揭示，
   `flash` 只用于强烈冲击。它们覆盖边界、不缩短时间轴；仍需说明动机，不用转场掩盖缺少画面。
2. **需要两世界共存才用重叠式**：`fade` 表达时间流逝或记忆，`slide`/`wipe` 表达方向关系，`iris` 表达视野收放，
   `zoom-blur`/`linear-blur`/`cross-zoom` 表达快速空间变化。窗口由 resolver 校验，不能撞相邻转场或越出正片。
3. **match-scale 需要匹配主体**：上一章主体的形状、位置和下一章入口对应，例如芯片特写变成芯片内的电路世界。
   运行时只提供缩放与混合，匹配关系必须自己构图；不能任意两张卡片缩放一下就称为匹配剪辑。

跨章硬切也可以有意使用（强对照、节拍段），但要在计划和审片中说明。kind、窗口和本地帧语义见
[场景轨 API](api.md#场景轨)。转场 cue 与配方 cue 一起进入 [音效轨](sound.md)，避免重复叠声。

## 先避开最常见的失败：逐页幻灯片

下面这些信号同时出现时，成片读起来像 PPT，而不是影片：

- 每段都是同一堆叠：顶部小标签和大标题、中间带边框的插图卡片、底部说明行、常驻页脚。
- 主体画在固定的正方形里再居中，只占画面四分之一，四周是没有设计的底色。
- 主体由文档图标、方框、圆点、问号和几条线组成，没有体积、光影或细节层级。
- 相隔数秒的帧几乎相同；动作只是在卡片里逐个淡入元素，镜头和主体尺度不变。
- 同一个意思同时写在标题、副标题、标签、说明和字幕里。
- 几十秒、多段落的片只有几十行代码。

最隐蔽的一种是“每段同一版式”：每段都在顶部放小标签和大标题、中间居中一个物体、底部是字幕。物体画得再精致，
观众看到的仍是一页一页翻过去。替代做法：

- 把名称做成场景里的标签（挂在物体上、跟着镜头运动），而不是每段固定在顶部的标题。
- 让多个对象住在同一个空间里，镜头在它们之间移动：例如逐级查询就沿一条路径从一个服务器推到下一个，
  而不是每段把一台机柜摆在正中间。
- 同类对象要在形体、尺度或位置上能区分开，不要每级都用同一个模型换标签。
- 用取景变化（俯视、侧视、特写、全景）区分段落，让相邻两段的构图一眼就不同。

## 构思

- **语义优先**：按证据、机制、对比或因果过程选择效果，不套固定品牌叙事。
- **一句话主张**：观众看完要记住什么。每段旁白都服务这个主张，并让上一段的结果引出下一段。
- **代表画面**：给每段写一句关键画面：取景（特写、全景、俯视、剖面、跟随）、主体位置和大致占比、
  铺满画面的环境、前景遮挡、文字放在哪块安静区。相邻段落的取景要能明显区分。
- **一个连续世界**：同一个空间和主体贯穿多段，用推拉、换位、主体变形完成变化，比每段换一张新卡片更像影片。
  换到另一个空间时用有动机的转场（遮挡、匹配动作、主体放大成为下一场景）。
- **表现手法按主题选**：插画或照片质感用生成图片；精确图解和状态变化用原创 SVG；软件和开发题材用真实界面组件；
  空间关系先用世界镜头和分层表达，本批配方以 SVG/DOM 为主。不要默认用几何图标。

## 设计

- **配色**：定底色、正文、辅助、强调四个角色；强调色只用在关键落点。场景美术可以用题材需要的颜色。
  以手机缩小观看检查亮度和对比，暗场也要让主体、状态标识和正文清楚，不强制使用某种配色。
- **文字对比自检**：文字不要横跨明暗交界，深色字不要放在深色背景上。逐条回应 `low-contrast-text`，
  核对帧号、最差网格位置与实际对比；有底板、描边或阴影也要看实渲染像素，转场和同组形变不免检，unknown 不算通过。
- **主体足够大**：关键画面中主体约占画面面积 40–60%，特写更大；不把主体关进带边框的卡片。
- **按真实画布设计**：以 `useVideoConfig()` 的宽高为坐标，竖屏就为竖屏构图；环境层铺满画面。
- **景深**：后景 → 中景 → 主体 → 前景遮挡 → 稳定文字。用一致的边缘、投影和透明度表达前后关系。
  前景元素不能压住正在阅读的文字；把文字放到安静区或调整前景路径，阅读期间保持完整可见。
  单屏舞台用 `ProducerShotStage`；要在场景里移动时用 `ProducerWorldCamera`（见“运动与节奏”）。
- **文字预算**：除字幕外，同一时刻最多一个短标题，加上最多 3 个贴在物体上的短标注（名称、数值、单位，如
  “蓝光 450 nm”“氮气 N₂”）。标注挂在它说明的物体旁、随镜头移动，不重复字幕整句。
- **数量要画出来**：旁白里出现数字、倍数、比较或变化趋势时，画成条形、刻度、计数或前后对照，让数值本身可见；
  只把数字写成一行字，静音的观众看不出差别有多大。
- **静音也能看懂**：讲解片的画面要独立讲清机制。关掉声音只看画面，观众应能说出每段发生了什么、为什么。
  来源、日期之类的说明在片尾或发布简介里出现一次。
- **字号**：竖屏 1080 宽时正文标签不小于约 36px，标题 64px 以上；以手机上缩小观看为准。
  字体用 `"Noto Sans SC", "PingFang SC", sans-serif` 一类已安装字体，不依赖合成粗体。

「已发生 / 迹象 / 推测」等内容状态标识属于账号内容红线，统一用 `FilmStatusTag`，不手写。
主词和副词都要达到 `minimumReadableFontSize(width, height)`，并且不低于实测字幕字号的 70%；
副词与主词保持同一可读对比层级。位置全片固定：默认左上角安全区（`position` 省略即 `top-left`），观众靠固定位置一眼分辨事实还是推测；只有与主体冲突时才换到另一个固定角，并在 storyboard.md 写明原因和起止帧；任何时候都不压住主体或正在阅读的文字。组件提供底板，放在场景轨之外，避免随镜头缩小；
自定义 `style` 后仍须核对 `small-status-tag` 并按手机观感看图确认大小与对比，不能当小字装饰。

### SVG 精作配方

- **分层**：全幅背景板（渐变、光照、环境形体）→ 中景 → 主体 → 前景遮挡 → 文字。
- **体积与光影**：统一光源方向；用 `linearGradient`/`radialGradient` 表达体积，加接触阴影和边缘高光。
- **细节层级**：主体有大形、中形、小细节三级；图标、方框、问号只做点缀，不充当主体。
- **线条体系**：全片统一 2–3 种描边粗细和圆角规则。
- **材质**：复用一个共享 pattern 或细颗粒，放在主体内部，不逐元素加滤镜，不盖住文字。

## 运动与节奏

按 [导演手册第 4–5 节](direction.md#4-三层动效核心) 搭 L1/L2/L3。每小节都有 L2，讲述段也不例外；
镜头走一步就稳住阅读，不做匀速慢漂。大世界用 ProducerWorldCamera，空间关系先设计在小节表里；
画面只有一屏时用 ProducerShotStage。一个镜头一个主动作，背景和环境光做次级呼吸，阅读文字稳定。

## 审片

完整清单、逐小节 storyboard、animatic 听审与所有 motionWarnings 回应要求，统一见
[导演手册第 8–9 节](direction.md#8-storyboardmd-写法)。至少完成一轮“审片 → 修改 → 再审片”，
按手机尺寸看图，unknown 不算通过，联系表不替代连续带声音预览。
