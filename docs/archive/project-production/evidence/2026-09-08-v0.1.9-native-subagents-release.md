# 0.1.9 native subagent reliability release

Status: **Both packages released; official registry Codex and Hermes video verification passed.**

## Change and verification

The published Workspace defaults to native `subagents` with maximum concurrency four. Public Skill routing separates the Root's global doctor/preflight from assigned workers' bound task execution. Each different TaskRevision requires a fresh child session; completed workers cannot receive a different task through follow-up/resume. Existing inline preferences and fixed failure semantics remain unchanged.

macOS process-group cleanup retains its safety checks while preserving sanitized `/bin/ps` inspection diagnostics. The release audit recognizes Hermes native `tool_call` bridges only after matching the original invocation and result tool name. It does not relax task ownership, evidence provenance or delivery checks.

- Local macOS: 811 tests passed, zero failed or skipped; package typecheck/build, docs links and zero-vulnerability audit passed.

- [Candidate receipt](v0.1.9-first-use.json): both hosts passed with 5 production children plus 1 probe, peak four and one queued admission each. Original continuations succeeded; seven final checks, exact-four files, checksums and EOF decode passed. Candidate Codex video: 805 frames / 26.83 seconds; Hermes: 830 frames / 27.67 seconds.
