## Verification and limitations

The local full check passed 793 tests, typecheck, lint, documentation links, package builds and host compositions; npm audit reported zero vulnerabilities. The later public-bin recorder regression is checked separately before committing the release. CI reruns the complete suite against the exact release source.

Initial installation trials were mistakenly nested under the existing `/Users/ai/AgentWorkspace/axmorf` Workspace and correctly failed bootstrap's multiple-marker protection. No video Agent had started there. Only the controller's acceptance directory was moved to a sibling location; the original user workspace remained unchanged. These trials are excluded from first-use acceptance. The recorder's initial direct internal-file invocation was also corrected to the verified public CLI bin before receipts were issued; this did not modify or retry either production.

This is two hosts on one model/Mac/default narration configuration, with unattended CLI approvals. It does not certify every model, OS, permission interaction, revision or recovery scenario. Each video was fully decoded and sampled visually; there is no claim of subjective audio review or exhaustive frame-by-frame visual acceptance.
