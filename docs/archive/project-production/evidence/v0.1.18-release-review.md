# 0.1.18 merged release review

Date: 2026-10-08. This records engineering and the maintainer-approved release scope;
registry publication is recorded separately after completion.

The default branch `axmorf/npm-workspace-open-source` was at the 0.1.16 closeout
`c3431f6` when continuous-film development began. The published 0.1.17 tag
`3b2a01c` and the `axmorf/visual-narrative-quality` branch still existed. That branch's
closeout `d323d69` had not been merged into the default branch. Beginning development
without checking the newer release branch was an engineering baseline error.
The continuous-film work was preserved and pushed as `c2bb058`; this release merges
both histories without rewriting either published tag or removing another worktree.

The merge preserves published visual-scene durations, null narration manifests,
shared SVG handoffs, bound Scene previews, full-composition music and narrow
boundary/music revisions. It adds filmPlan, continuous multi-Beat ownership,
explicit silent-owner frame timing, frozen whole-film preview, shared camera/event
utilities, single AAC encoding and presence-aware revision snapshots. Existing
Story timing and frozen layouts retain their contracts. Both authored timing paths
use zero providers and support continuous Scene ownership. New default music keeps
the 0.1.17 composition scope; explicit content-window tracks retain their scope.

Merge regressions cover both frame paths, grouped ownership and sound, no-narration
source health, task contracts and previews, candidate creation/promotion/rollback,
publishing chapters, package/scaffold exports and generated guidance. The discovered
authored scene-review chapter mismatch now has a regression test; stale chapters
are still rejected. The Skill keeps its original context budgets. Production
checks retain strict identity, exact-file and source-integrity requirements. Remotion
and direct dependency versions and browser sandbox requirements are unchanged.
The final audit identified two newly disclosed transitive dependency advisories.
Root and generated Workspace overrides pin the official patched versions:
[postcss-selector-parser 7.1.6](https://github.com/advisories/GHSA-rj75-hqrm-r3gf)
and [source-map-js 1.2.2](https://github.com/advisories/GHSA-68fv-2mgg-jv7q).
The dependency audit, scaffold contract and package/render checks are repeated for
these patch updates; they do not change the pinned Remotion version.

The maintainer directly requested commit, push and publication without repeating
the previously reviewed videos, then approved “完成合并并复验受影响部分（推荐）”.
The approved scope therefore reuses the retained
[0.1.17 native receipt](v0.1.17-first-use.json),
[continuous-video engineering acceptance](2026-10-08-continuous-video-acceptance.md)
and [creative-video Skill review](2026-10-08-creative-video-skill.md), each at its
original package identity and observation limits. They do not certify the merged
0.1.18 packages as a fresh ordinary-prompt native first-use run. Exact-four native
concurrency, continuous subjective review and listening have not been repeated.

The strict release plan binds this version, these evidence checksums and the newly
built package content fingerprints. An explicit workflow invocation for `v0.1.18`
approves this reuse; omission retains the normal fresh native gate. The result is
identified as reviewed acceptance reuse with `nativeFirstUseVerified:false`.
New package build/type/source checks, affected regressions, fresh external
installation and doctor, minimal real render, EOF decoding, exact archive integrity
and trusted-publisher provenance remain required. Public packages are immutable;
the default branch and new release tag will both contain the merged release code.

Future work must compare the checkout with the newest published tag and release
branch before choosing its baseline. A tag published from an isolated release branch
does not automatically merge that branch into the default branch.
