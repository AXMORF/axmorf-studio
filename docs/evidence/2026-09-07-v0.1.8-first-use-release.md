# v0.1.8 first-use reliability release

## Implemented

- Public create context supplies a complete nonempty requirement object example. Raw create/revise schema errors expose field paths and repair guidance; stored-artifact errors remain operational failures. Validators retain their strict requirements.
- Diagnostic duration budgets subtract silent boundaries and render padding from the requested total. Inspect reports unknown measured timing until verified sealing; prepare and fixed completion report PCM-derived total and signed deviation. No identity change, implicit tolerance, truncation or production retry.
- Creator reports install/bootstrap/browser/doctor stages and elapsed time, including a 30-second waiting signal. npm output remains visible; retained npm logs survive staging cleanup.
- The [first-use release gate](../guides/FIRST_USE_RELEASE_GATE.md) executes the exact candidate creator, rejects existing workspaces/caches, audits native Codex/Hermes sessions, verifies unchanged package/guide content and revalidates exact delivery files. npm publication requires the matching two-host receipt before publishing either package.

## Verification and limitations

The local full check passed 793 tests, typecheck, lint, documentation links, package builds and host compositions; npm audit reported zero vulnerabilities. The later public-bin recorder regression passed separately. Both macOS ARM64 and Ubuntu publication CI ran the complete 794-test suite successfully against release source `15f89958a217f233b5539893746755c877d59bf9`.

Candidate success included Agent-owned output corrections. Codex repaired draft output directory and renderer validation issues before committing its tasks. This acceptance measures completion without user intervention; it does not certify zero errors.

Initial installation trials were mistakenly nested under the existing `/Users/ai/AgentWorkspace/axmorf` Workspace and correctly failed bootstrap's multiple-marker protection. No video Agent had started there. Only the controller's acceptance directory was moved to a sibling location; the original user workspace remained unchanged. These trials are excluded from first-use acceptance. The recorder's initial direct internal-file invocation was also corrected to the verified public CLI bin before receipts were issued; this did not modify or retry either production.

This is two hosts on one model/Mac/default narration configuration, with unattended CLI approvals. It does not certify every model, OS, permission interaction, revision or recovery scenario. Each video was fully decoded and sampled visually; there is no claim of subjective audio review or exhaustive frame-by-frame visual acceptance.
