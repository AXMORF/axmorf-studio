# v0.1.7 macOS process snapshot correction

## Reproduced defect

Both actual Hermes and Codex hosts completed videos with official v0.1.6. Subsequent concurrent, read-only public final checks
reproduced a false cleanup failure. An observation-only preload captured `SIGKILL EPERM`, signal-zero `EPERM`, and a full
`ps` snapshot with no target group. An unrelated exiting process had the valid unknown state `?E`; the parser rejected the
entire table because it only accepted alphabetic state prefixes. Installed package and delivery bytes were unchanged.

Apple’s [process state table](https://github.com/apple-oss-distributions/adv_cmds/blob/main/ps/tasks.c) includes `?`,
and its [ps formatter](https://github.com/apple-oss-distributions/adv_cmds/blob/main/ps/print.c) emits `E` for an exiting process.
The correction accepts macOS process-state syntax without treating an unknown state in the target group as proof of exit.
Only a missing target group or exclusively zombie members can prove no writer remains. Inspection remains bounded and
fail-closed for malformed output, active or unknown target members, command failure and timeout. No signals, providers or
production attempts are retried, and validators and Chromium sandbox settings are unchanged.

## Verification and release

The two new regressions failed before the fix. After the minimal source correction, all 26 focused process/browser/ownership
tests passed, along with TypeScript and ESLint checks. An independent review replayed the observed snapshot: the absent
original target group is accepted, while the unrelated group containing `?E` is rejected as a target.

All 778 repository tests passed without failures or skips. Package build/typecheck, lint, documentation links, static
checks, compositions and host gates passed. The corrected source public adapter independently checked both real v0.1.6
Deliveries concurrently for five rounds (ten successful final checks), using their installed runtime policy and without
modifying installed packages or Project bytes.

Native macOS release gate and official npm publication are pending.
Fresh latest-package installation and two actual Agent video runs will be recorded after publication.
