# v0.1.2 System preview audio release

> 文档类型：可复核实施证据
>
> 验收日期：2026-09-03

## Outcome

Exact commit `ce3ef9f9f6b99c5401ae5024cf4f624bbbca37d0` 已通过 annotated tag `v0.1.2` 公开发布：

- `@axmorf/studio@0.1.2`
- `create-axmorf-studio@0.1.2`
- [GitHub Release v0.1.2](https://github.com/AXMORF/axmorf-studio/releases/tag/v0.1.2)

`DefaultIntroPreview` 与 `DefaultOutroPreview` 不再从空的默认 audio projection 构建。runtime 会从 package-owned、
schema-validated asset manifest 解析两条 policy-covered shared WAV identity，再按既有 cue、anchor、duration 与 volume
生成默认 preview sound contribution。Project create 和显式 template audio projection 仍走原有 exact input，不受
这个 preview fallback 改变。

回归测试不再允许 `audio: null` 作为通过条件，而是锁定两条 package-owned public path、角色和完整 cue duration。
package manifest gate 同时改为校验 root/runtime exact version 一致，避免每次 patch release 留下硬编码旧版本。
