# 纸拼贴 / Vox 风格案例

这是 [创作手册](creative-playbook.md) 的可选案例。借鉴的是物体、构图、触感和落点的做法，不要求未来作品都采用这组颜色、图标或网站内容。实际主题、横竖屏、口播和冻结合同优先。

## 先建立物体，再加纸感

让抽象内容有物理动作：想法可变成待整理的纸片，流程可变成装配中的物件，作品展示可成为打开的一张折页。每个物体有初态、受力动作和结果，图标应能脱离标签被辨认。

可以用一个主物体连续展开全段，而不是每句都另开 Scene。相机跟随展开、进入局部或揭示关系；完整结果出现时稳定。前景遮挡可用于交接，但不能吞掉阅读窗口。

| 层 | 工艺 | 常见失误 |
| --- | --- | --- |
| 纸芯与纤维边 | 先画略扩张的浅色外轮廓，再叠有色纸面；边缘有少量可重复的法向偏移 | 整圈锯齿太大像齿轮；每帧 random 造成闪烁 |
| 纸面 | 保留清楚的色面，叠轻颗粒、局部半调或折线 | 把噪声当填色，导致颜色脏灰 |
| 接触与厚度 | 紧贴边缘的接触阴影加较软的远阴影，方向一致 | 每张纸都厚重发光，物体漂浮 |
| 折叠 | 面的遮挡顺序、折痕、明暗共同显示体积 | 只画三角形，视觉上没有折叠关系 |
| 注释 | 对应结果出现后画圈、短线或笔迹，位置避开字面 | 提前乱画；粗下划线盖住文字 |
| 胶带与碎纸 | 少量固定连接关系或强调受力结果 | 只为填空；碎纸飞过主要阅读区 |

粗边由固定 seed 决定。有限纸片可采用低频 stepped boil；重要文字稳定。进度必须由 frame 直接计算，任意跳帧结果一致，不靠上一帧积累物理状态。

## 构图比滤镜更重要

原作者展示了标题物体从前稿到后稿的变化：[前稿 f40](../examples/opus-playbook/images/before_title_f40.jpg)、[后稿 f55](../examples/opus-playbook/images/after_title_f55.jpg)。这两张不是同一时刻，不能用于量化运动改善。

从实际图像能看到：后稿用深色后盘衬托多色折面与浅色纸芯，主体体积和分离度更清楚；文字条与物体之间形成遮挡层级。可借鉴“后景支撑主体”和“不同面表达折叠”，不要照抄具体三角形或标题位置。该前稿截图不能单独证明原文描述的所有同色问题。

[原案例场景总览](../examples/opus-playbook/images/v3_sheet_scenes.jpg)展示了不同章节使用不同主角、色面和空间结构。它也是提醒：小字和标签很多，不能仅凭材质丰富就认定所有阅读窗口都合格。

用当前主题角色改变面积和关系：大面积底色、清楚的前景主体、较少的辅助物、局部强调。横屏可让主体和文字左右建立张力；竖屏可沿纵向动作展开，保留顶底安全范围。按 viewport 重排，不能仅将横屏缩小放到竖屏中。

## 动作、音效、留白

| 物体动作 | 视觉设计 | 声音语义 |
| --- | --- | --- |
| 重纸片盖章 | 提前下降，接触帧明确，短余振后稳定 | stamp 起音对齐接触 |
| 轻纸片滑入 | 先进入画面，再与目标连接；少量轻回弹 | swell 中心接近连接点，或保持安静 |
| 折页打开 | 铰链与遮挡随展开改变；结果平面保持 | 可用轻纸声，不要求每个折面都响 |
| 画线确认 | 线随进度生长，在字下留间距 | pencil 跟随真实画线段，不跟整个 Scene |
| 标签附着 | 附着处准确，错开主要内容，给阅读停留 | 短 pop / ding，只强调有意义的确认 |

避免把每个元素都套同一 spring。重物、轻纸、笔迹分别采用适合的预备、接触和稳定节奏。允许接触后余振；计算阅读预算时从清楚稳定的位置开始。

音乐可使用短拨弦、温暖低音、刷子或 shaker，形成轻巧手工气质；这只是此风格的一种选择。编曲在密集动作与安静阅读之间改变，不由滤镜或全片加响替代。

## 使用范围

先由 Root 把需要的机制写入当前 brief，再由 bound executor 在本次 context、viewport 和资源范围内原创实现。历史完整 Scene 不发给 worker 作为复制模板，也不把原案例源码自动提升成共享 capability。

本仓库的 [可运行落点小样](../examples/cue-lab/README.md)只演示粗边、折面、分层、预备/接触/稳定、统一 cue 和代码音轨。它不是生产模板，不证明独立构思质量，也不代替正式 Project 的权限、时序、封面和四文件交付。
