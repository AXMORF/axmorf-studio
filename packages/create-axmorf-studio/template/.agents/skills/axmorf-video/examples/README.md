# 创作案例与示例

主方法在 [创作手册](../references/creative-playbook.md)，纸张工艺在 [Vox 案例](../references/paper-collage.md)。Root 规划时选用与内容有关的机制；当前 brief、冻结时序和已批准资源决定实际实现。

| 示例 | 用途 |
| --- | --- |
| [音乐主导 brief](music-led.md) | 无口播，展示连续主体与音乐事件如何组织一段内容 |
| [口播主导 brief](voice-led.md) | sealed 旁白优先，在语义范围内选择音乐落点 |
| [可运行落点小样](cue-lab/README.md) | 独立 8 秒 Remotion 示例，横竖两版、97 BPM、代码配乐与音效 |
| [来源原文](opus-playbook/README.md) | 用户附件原始全文、对比图、校验值与适用限制 |

示例里的题材、时长、字体和配色不是未来作品的固定值。brief 是设计说明，不是直接可提交的 create-input JSON；使用当前 `project:create:context` 的完整字段示例与安装版本的公共合同。

小样输出写到独立 `out/creative-playbook/`，不修改任何 Project。正式制作继续使用 Skill 的 prepare、绑定、预览、固定 continuation 和 revision 流程；不要把教程渲染命令当作正式 Delivery 的替代。
